# 板材裁切排样台

面向木工、亚克力加工与手作用户的矩形板材裁切排样（Nesting）Web 应用。
后端为 Python Flask 本地服务，前端为原生 HTML / CSS / JavaScript / SVG，**不依赖任何在线 API**，可完全离线运行。

## 功能

- **原料板与零件定义**：多张板材（尺寸、数量、纹理方向）与多种矩形零件（尺寸、数量、可旋转性、纹理方向）。
- **工艺参数**：锯缝（kerf）、板边留量、零件间距。零件间净距 = 锯缝 + 零件间距。
- **多方案排样**：内置多种排序策略（面积/长边/短边/宽度/高度降序）的 Bottom-Left 排样引擎，
  一次生成最多 3 个方案，按 未放置数 → 材料利用率 → 切割次数 排序对比；
  统计材料利用率、废料面积、估算切割次数（贯通切割 + 修边）。
- **未放置解释**：区分"尺寸超出所有板材可用区域"（含纹理限制说明）与"剩余空间不足"，
  因缺陷无法避让时写明冲突的板材实例与具体缺陷编号（点击提示可定位）。
- **板面缺陷避让**：针对每张板材**实例**在 SVG 上绘制/拖动/拉顶点调整矩形或多边形缺陷，
  登记类型（节疤/裂纹/划痕）、等级（1–3）、影响面（正面/反面/双面贯穿）与安全外扩量，随板材实例及项目保存；
  零件可设置正反面要求、允许缺陷等级，并在零件示意图上圈出容许缺陷区域。
  排样时把缺陷核心+安全外扩、板边留量、锯缝/间距一并纳入 Bottom-Left 放置计算；
  判定规则：面别不相遇（单面缺陷可翻板避让，双面/贯穿缺陷不可）且
  （等级 ≤ 允许等级 **且** 核心整体落在容许区内）才可覆盖缺陷核心，零外扩时仅严格重叠阻止，外切不阻止；
  拖动零件或缺陷后立即复核，画布叠加显示缺陷核心、安全外扩边界与受影响零件。
  方案按 合格零件数 → 使用板材数 → 利用率 → 避让碎料面积 → 切割次数 比较；
  打印图标明缺陷轮廓、编号、类型/等级/影响面与避让距离，并列缺陷清单。
- **交互画布（SVG）**：滚轮缩放、空白拖拽平移、零件拖拽（支持跨板移动）、R 键旋转、
  方向键微调；实时标出 重叠（红）/ 越界（红）/ 间距不足（橙）/ 纹理方向（紫）违规。
- **裁切工序演练**：把当前排样拆成可执行的贯通切割树——每刀都是当前子板上的一条
  贯通横/竖直线，锯缝计入损耗；给出切前子板尺寸、切线位置、产出的零件与余料。
  底部面板逐刀播放（空格）、前后切换，画布高亮当前子板、切线、锯缝带与新产生的板块；
  步骤在依赖允许时可上下换序、可切换候选切法，实时比较总刀数、翻板次数与可复用余料面积；
  无法贯通裁切的区域标为阻塞区并归入人工处理项；拖动/旋转零件后旧工序自动失效并重新分析；
  工序状态（切法选择、步骤顺序、播放进度）随项目保存恢复。
- **锁定与重排**：L 键锁定已排零件，"保留锁定重排"在锁定区域不动的前提下重新排样。
- **撤销 / 重做**：Ctrl+Z / Ctrl+Y，最多 100 步。
- **本地持久化**：项目保存到 SQLite（`data/projects.db`），可随时打开继续编辑。
- **打印视图**：独立打印页，含板材尺寸标注、零件编号与尺寸、按已选工序编号的切割线
  （蓝色虚线）、裁切工序表（切法/切线位置/切前子板/行程/产出）、人工处理项与零件清单，A4 横向。

## 运行

```bash
pip install -r requirements.txt
python app.py
```

然后浏览器打开 <http://127.0.0.1:5000>。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 滚轮 | 缩放（以光标为中心） |
| 拖动空白 | 平移画布 |
| 拖动零件 | 移动（可跨板） |
| R | 旋转选中零件（受可旋转/纹理约束） |
| L | 锁定 / 解锁选中零件 |
| Delete | 从板材移除选中零件（回到未放置列表） |
| 方向键 | 微调位置（Shift = 10mm） |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做（含缺陷绘制与拖动） |
| Enter | 多边形缺陷绘制时闭合（也可双击或回到起点） |
| 空格 | 裁切工序面板打开时：播放 / 暂停 |
| Esc | 取消当前多边形草稿 / 退出绘制或放置模式 / 取消选择 |

## 项目结构

```
app.py              Flask 入口与 REST API（排样、项目 CRUD）
nesting.py          排样引擎（Bottom-Left + 多策略 + 切割估算 + 缺陷避让几何）
templates/index.html
static/css/style.css
static/js/          state / api / defects / validate / parttol / canvas / cutplan / cutui / ui / print / main
data/projects.db    SQLite 数据库（首次运行自动创建）
```

## 说明与约定

- 仅处理**矩形零件**与**直线切割**；方案标签中的切割次数为估算值（递归贯通切割 + 修边）。
- **裁切工序模型**：一刀 = 当前子板上的一条贯通直线；切线位置为锯片左/上缘，
  锯缝带 `[at, at+kerf]` 计入损耗；子板与零件完全一致即产出零件，无零件子板为余料
  （短边 ≥ 100mm 视为可复用）；找不到贯通切线的区域为阻塞区，剩余裁切归入人工处理。
  翻板次数 = 相邻两刀方向（横/竖）变化次数。
- 纹理方向：`横向` = 纹理须沿板材宽度方向（禁止旋转）；`纵向` = 须旋转 90°；`无` = 任意（受"可旋转"约束）。
- 坐标原点在板材左上角，单位毫米。
