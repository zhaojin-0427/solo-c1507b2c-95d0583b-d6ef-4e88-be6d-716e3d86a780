# 板材裁切排样台

面向木工、亚克力加工与手作用户的矩形板材裁切排样（Nesting）Web 应用。
后端为 Python Flask 本地服务，前端为原生 HTML / CSS / JavaScript / SVG，**不依赖任何在线 API**，可完全离线运行。

## 功能

- **原料板与零件定义**：多张板材（尺寸、数量、纹理方向）与多种矩形零件（尺寸、数量、可旋转性、纹理方向）。
- **工艺参数**：锯缝（kerf）、板边留量、零件间距。零件间净距 = 锯缝 + 零件间距。
- **多方案排样**：内置多种排序策略（面积/长边/短边/宽度/高度降序）的 Bottom-Left 排样引擎，
  一次生成最多 3 个方案，按 未放置数 → 材料利用率 → 切割次数 排序对比；
  统计材料利用率、废料面积、估算切割次数（贯通切割 + 修边）。
- **未放置解释**：区分"尺寸超出所有板材可用区域"（含纹理限制说明）与"剩余空间不足"。
- **交互画布（SVG）**：滚轮缩放、空白拖拽平移、零件拖拽（支持跨板移动）、R 键旋转、
  方向键微调；实时标出 重叠（红）/ 越界（红）/ 间距不足（橙）/ 纹理方向（紫）违规。
- **锁定与重排**：L 键锁定已排零件，"保留锁定重排"在锁定区域不动的前提下重新排样。
- **撤销 / 重做**：Ctrl+Z / Ctrl+Y，最多 100 步。
- **本地持久化**：项目保存到 SQLite（`data/projects.db`），可随时打开继续编辑。
- **打印视图**：独立打印页，含板材尺寸标注、零件编号与尺寸、切割顺序编号（蓝色虚线）、
  切割顺序表与零件清单（含坐标位置），A4 横向。

## 运行

```bash
pip install -r requirements.txt
python app.py
```

然后浏览器打开 <http://127.0.0.1:5000>。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 滚轮 | 缩放（以光标为中心） |
| 拖动空白 | 平移画布 |
| 拖动零件 | 移动（可跨板） |
| R | 旋转选中零件（受可旋转/纹理约束） |
| L | 锁定 / 解锁选中零件 |
| Delete | 从板材移除选中零件（回到未放置列表） |
| 方向键 | 微调位置（Shift = 10mm） |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Esc | 取消放置模式 / 取消选择 |

## 项目结构

```
app.py              Flask 入口与 REST API（排样、项目 CRUD）
nesting.py          排样引擎（Bottom-Left + 多策略 + 切割估算）
templates/index.html
static/css/style.css
static/js/          state / api / validate / canvas / ui / print / main
data/projects.db    SQLite 数据库（首次运行自动创建）
```

## 说明与约定

- 仅处理**矩形零件**与**直线切割**；切割次数为估算值（递归贯通切割 + 修边）。
- 纹理方向：`横向` = 纹理须沿板材宽度方向（禁止旋转）；`纵向` = 须旋转 90°；`无` = 任意（受"可旋转"约束）。
- 坐标原点在板材左上角，单位毫米。
